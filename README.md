# 陪玩小工具

陪玩小工具是一个完全离线的 Electron 桌面计时与计费工具，用于在本地记录会话、暂停/继续、查看历史、导出 CSV，以及在主窗口和迷你窗之间切换查看当前状态。

## 特性概览

- 完全离线运行，不依赖登录、网络服务或云端接口。
- 不提供账号系统，不做云同步，不上传遥测数据。
- 会话、设置和历史数据保存在本机目录中。
- 主窗口负责计时、历史和设置；迷你窗用于紧凑展示当前会话状态。
- 历史记录支持独立编辑时间片段，CSV 导出使用统一的本地序列化逻辑。

## 快速开始

### 安装依赖

首次在本地拉起开发环境时，可以使用：

```bash
npm install
```

如果你需要基于锁文件做更稳定、可复现的安装，使用：

```bash
npm ci
```

### 开发启动

```bash
npm run dev
```

### 常用脚本

- `npm test`：运行 Vitest 测试。
- `npm run test:e2e`：运行 Playwright Electron 端到端测试。
- `npm run typecheck`：运行 TypeScript 类型检查。
- `npm run build`：执行 `electron-vite build`。

## 打包

当前仓库提供两个平台专用打包脚本：

```bash
npm run package:mac
npm run package:win
```

这两个脚本都会先执行 `electron-builder install-app-deps`，再构建 Electron 应用，最后分别调用：

- `electron-builder --mac dmg`
- `electron-builder --win nsis`

仓库当前只定义了 macOS 和 Windows 的本机打包路径，没有在文档中承诺 Linux、Wine 交叉构建、签名、公证或自动更新。

当前安装包属于未签名/未公证的早期桌面分发形态，首次打开时 macOS Gatekeeper 或 Windows SmartScreen 可能会提示来源未验证。如果你确认安装包来自可信来源，请按照系统提供的常规安全提示、右键打开选项或图形界面中的允许入口完成放行，不要关闭系统安全机制。

## 本地数据与隐私

- 应用是本地优先工具：数据保留在当前设备中。
- 不需要登录。
- 不提供云同步。
- 不包含遥测或远程上报流程。
- CSV 导出为本地文件导出，不依赖远程服务。

本地数据保存在 Electron 用户数据目录下，具体路径会因操作系统不同而变化。可以把它理解为“当前系统为这个应用分配的本地应用数据目录”，其中会包含数据库和相关本地状态文件。

如果你需要清空本地数据，请先完全退出应用，再删除该应用对应的本地数据目录或其中的数据库文件。删除前建议先自行备份，因为这会移除当前设备上的历史记录与本地设置。

测试与 E2E 夹具中会使用 `ELECTRON_USER_DATA_DIR` 覆盖用户数据目录，便于隔离测试环境；这属于测试/自动化用途，不应视为面向普通用户的运行时功能说明。

## 窗口与界面

- 渲染层会根据 `?window=main|mini` 区分主窗口和迷你窗。
- 主窗口包含计时、历史和设置入口。
- 迷你窗只展示当前快照与相关操作，不复制另一套状态机逻辑。
- 如果本地数据库初始化失败，应用会显示启动错误页，而不是进入正常计时界面。

## 常见问题

### 1. 为什么没有登录、账号或云同步？

因为这个工具当前设计就是完全离线、仅本地存储的数据工具。

### 2. 数据保存在哪里？

数据保存在 Electron 用户数据目录下的本地文件中，实际路径会因 macOS 或 Windows 而不同。测试环境可能会通过 `ELECTRON_USER_DATA_DIR` 指向临时目录，但正常使用以系统默认的本地目录为准。

### 3. 如果系统提示安装包未验证怎么办？

早期未签名安装包在 macOS Gatekeeper 或 Windows SmartScreen 下出现来源提示是正常现象。如果你确认安装包来源可信，请使用系统提供的常规允许入口继续，而不是关闭或绕过系统安全机制。

### 4. 如何删除本地数据并重置应用状态？

先完全退出应用，再删除 Electron 用户数据目录下该应用对应的本地数据文件夹或数据库文件。路径名称会随操作系统而变化；删除前请先备份需要保留的本地数据。

### 5. 为什么打包前要先执行 `electron-builder install-app-deps`？

仓库依赖 `better-sqlite3` 这类原生模块，打包前先执行该命令可以让原生依赖重新对齐 Electron ABI。

### 6. 如果启动后没有进入主界面怎么办？

当前实现中，本地数据库初始化失败时会显示启动错误页。优先检查本地数据目录状态，再重新启动应用。

### 7. 历史编辑和 CSV 导出会联网吗？

不会。历史编辑和 CSV 导出都在本地完成。
